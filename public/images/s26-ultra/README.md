# Samsung Galaxy S26 Ultra Image Sequence

Place the exploded-view image frames in this directory.

## Requirements

1. **Format**: `.jpg`
2. **Naming Convention**: `ezgif-frame-001.jpg` to `ezgif-frame-028.jpg`
3. **Total Frames**: 28
4. **Lighting**: Keep lighting, camera position, and background consistent across all frames.
5. **Background**: Should match `#050505` to seamlessly blend with the website.

Example:
```
/public/images/s26-ultra/ezgif-frame-001.jpg
/public/images/s26-ultra/ezgif-frame-002.jpg
...
/public/images/s26-ultra/ezgif-frame-028.jpg
```
